# California-Health-Employment

This repository contains the data and code to generate estimates in the Agglomerations post [Forget AI. The California job market is powered by healthcare](https://agglomerations.eig.org/p/forget-ai-the-california-job-market). Accurate as of time of publication, May 11th, 2026. Contact thomas@eig.org or kenan@eig.org with any questions.

All data required to replicate the analysis is included in this repository or pulled directly from the BLS and St. Louis Federal Reserve website in the code.

----------

### Data
Data for this piece comes from the following sources:

1. <b>Bureau of Labor Statistics:</b> [Quarterly Census of Employment and Wages](https://www.bls.gov/cew/)
2. <b>St. Louis Federal Reserve:</b> [Federal Reserve Economic Data](https://fred.stlouisfed.org/)
